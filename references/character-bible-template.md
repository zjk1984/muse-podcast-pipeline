# 人物圣经模板

> 以下四个主持人是**示例**，可整体替换。替换时保持结构：每人一张"人设卡"（三句话）＋一段小传（写稿时严格按人设走）。人物关系、团梗、弧光等机制可直接复用框架、换内容。

## 主持人卡模板

```
名字：
音色（TTS voice id）：
年龄 / 星座 / 出身：
身份（白天本职工作）：
性格（一句话）：
喜剧功能（一句话：他在对话里负责什么）：
口头禅（主口头禅＋2 个轮换说法）：
主场版块（认领 1–2 个）：
黑历史库（供自嘲用，2–3 条）：
个人偏好（写稿取梗用，可按需增删）：
  爱好 / 喜爱的明星 / 常看影视 / 爱听歌手和歌曲 / 擅长运动 / 玩的游戏 / 技能 /
  爱吃（偏好＋雷区） / 酒量 / 剁手（花钱爱好） / 想养的宠物（怕什么） /
  恋爱观（一句话） / 雷区（一提就炸的话题）
```

## 示例人设（可替换）

**示例 A —— 东北大妞型**：`示例-女主持A`
31 岁，射手座，东北姑娘。神叨善良（信星座塔罗）＋爱美作精（衣柜永远少一件衣服），但讲义气、嗓门大。大学学编导，转行开了家韩舞工作室当老板兼头牌老师。喜欢日漫国漫（聊到时两眼放光），韩语只掺词。喜剧功能：放声笑＋夸张反应，负责热场接梗。口头禅"哎妈呀"（轮换"得劲儿""老铁没毛病"）。主场：日漫国漫、影视综艺。黑历史：追星翻车、学舞翻车。个人偏好示例：爱好韩舞/追番/塔罗；爱吃奶茶半糖去冰＋烧烤组局；酒量自称酒神实际三瓶啤酒倒；剁手衣服化妆品；想养布偶猫（被室友以掉毛驳回）；恋爱观"要帅的会跳舞的，情绪稳定是底线"；雷区是年龄梗。

**示例 B —— 毒舌考据狂型**：`示例-男主持B`
31 岁，处女座，南方人，示例 C 的亲哥。学究式较真，口头禅"事实上…"（轮换"我考据了一下""这么说吧"），吵架爱摆事实甩证据，八卦都要考据出处；冷面刻薄，怼人时是王者；感情路上的倒霉蛋（相亲战绩惨烈），自己翻车时是青铜。娱乐自媒体主笔。喜剧功能：吐槽＋捧哏，一针见血。主场：科技 AI、GitHub 热榜、社媒热搜。黑历史：相亲翻车连续剧。个人偏好示例：爱吃清淡养生（保温杯泡枸杞）；酒量一杯倒，半杯上脸就开始考据酒文化；剁手买书；想养龟（省心），怕狗；恋爱观"灵魂共鸣比脸重要"；雷区是伪科学。

**示例 C —— 北京大姐型**：`示例-女主持C`
26 岁，金牛座，北京姑娘，示例 B 的亲妹。私房菜馆主厨。洁癖＋控制欲，怼人狠但会照顾人，刀子嘴豆腐心，关键时刻给搭档递台阶。喜剧功能：互怼主力＋投喂全员。口头禅"局气"（轮换"倍儿地道""这事儿交给我"），每期最多 2 次。主场：音乐（内娱向）、财经新闻。黑历史：后厨翻车、被房东拿捏。个人偏好示例：爱吃无辣不欢；酒量千杯不醉，负责把全桌喝趴再挨个送回家；剁手厨刀（刀比包贵）；想养柴犬，名都起好了；恋爱观"浪费粮食的一律出局"；雷区是浪费粮食。

**示例 D —— ABC 捧哏型**：`示例-男主持D`
25 岁，双子座，华裔 ABC。外企初级数据分析，具体干啥没人说得清、他自己也解释不清。中文是跟示例 B 学的，一锅"四味中文"；复杂汉语表达直接用英文代替（英文同样限初中水平）。喜剧功能：接梗补刀＋中文翻车。口头禅"Oh my God""你认真的吗"。主场：全平台游戏、音乐（英文歌向）。黑历史：中文闹笑话合集。个人偏好示例：爱吃汉堡薯条＋全糖珍珠奶茶，吃辣不行；酒量不详，每次团建都提前溜；剁手游戏皮肤；想养柯基，怕蟑螂；恋爱观"先搞懂自己干啥的再谈恋爱"；雷区是问他到底干啥的。

**示例关系网**：B 和 C 是亲兄妹（差 5 岁），互相攥着对方黑历史、核威慑式和平；A 和 C 住一屋、B 和 D 住一屋，两屋是对门邻居；D 的中文是 B 教的，第一个词就是"局气"。传说角色"房东老王"只活在台词里，从不出声、不配声音，是四人共同的吐槽靶子（口头禅"房租该交了啊"）。

## 选人规则

- **主场版块制度**：每人认领 1–2 个版块；看本期哪几个版块是重点，选主场对口的 **2–4 位**登场，不必每次全上。主场版块由认领人主讲，其他人捧哏拆台。
- 每期换着来，别连续几期同一批人；尽量保证男女声都有，别整期只有一个声线。
- 不登场的人本期不写台词、不配声音。
- 开场主咖：优先选本期重点版块的主场认领人，否则随机选。

## 飞行嘉宾位

常设，每两周请一位新嘉宾，保持新鲜感。人设现编：**一句话身份＋一句性格＋一个口头禅**。

**导游职责模板**（请导游/本地人型嘉宾主讲地域版块时）：除天气、路况、景点开放等实用信息外，还讲当地风土人情（民族、美食、习俗）、历史典故、旅行攻略（路线安排、避坑）、景区游玩推荐（景点、机位、最佳时间）；登场主持人捧哏提问，把话题往深了带。

**嘉宾登场三原则**：
1. **登场动机**：必须与本期话题强挂钩，不为请而请；开场 30 秒内点明"今天为什么请他来"。
2. **深度话题**：嘉宾每期带 1–2 个行业内幕、亲身经历或观点输出；有细节、有故事，不能只讲皮毛或只当捧哏。
3. **话题钩子**：嘉宾话题开场先抛悬念、反差或内幕感，留住听众。

**起名规则**：名字必须和身份、本期登场动机贴合、有记忆点（如新疆的哥叫"买买提"一听就是当地人），不用"小王""小李"这类路人名。

记入 topics 日志：`嘉宾：名字-身份-登场动机（一句话）`；同一嘉宾两周内不重复请。

## 关系圣经（结构示例）

登场的人之间是认识多年的老友：互相拆台不留情面、关键时刻互相兜底，有固定外号和内部梗；可以互相插话调侃，不用等轮到自己；调侃点到为止，不真吵架。

示例结构（替换人物时重写，但保留"固定关系＋可埋长线"的思路）：
- 年龄分组：30+ 老油条组 vs 20+ 熬夜组，互相使唤跑腿。
- 兄妹线：B 和 C 亲兄妹，互相攥黑历史，核威慑式和平（C 对亲哥嘴下留情，火力全开对 D）。
- 室友梗：C 爱干净有控制欲，A 大大咧咧——C 边收拾边怼，A 撒娇蒙混。
- 感情线（C & D，慢炖）：当众互怼→私下投喂→被起哄装傻；细水长流，一期只推进一小步。
- 损友线（A & B）：同龄互怼之王，但对方被外人欺负时第一个冲上去。
- 师徒线（B & D）：D 的中文是 B 教的，黑历史都是"教学成果"，定期被处刑。

## 团梗库

固定栏目，每期轮换 callback **1–2 个**，不用一次全上，可做连续剧式更新：
- **人物梗**（每人一个）：D 的工作之谜（每期试图解释一次、越描越黑）、A 的舞室招生（学生全是奇葩）、C 的新菜试吃（黑暗料理和爆款轮着来）、B 的相亲记（翻车连续剧）。
- **关系梗**：赌注结算（开场先结算上期赌注）、南北大乱炖（方言饮食互怼）、房东今日作妖（每期整一个新活）。
- **老梗**：D 的中文黑历史处刑、B 的八卦小本本、A 的韩语十级考试、C 的口头禅、A 的水逆。
- **固定小栏目**（每期选 1–2 个，按位置使用）：水逆播报（开场）、假如新闻发生在我们小区（版块内）、房东语音留言（串场，主持人模仿）、翻译官（版块内）、方言新闻播报（版块内）、离谱指数打分（结尾）、片尾彩蛋（道别后 30 秒翻车花絮）。

## 人物弧光

每人一条慢成长线（示例：B 相亲黄三次喜提外号、第四次遇到真命天女；A 舞室从招生难到开分店；C 菜馆上榜＋和 D 的感情线；D 从"不知道自己干啥"到升职、戒熬夜反复失败）。组合大事件一年 1–2 次（季终级别）。

规则：**每期最多推进一小步**，给长期听众追更感；有推进时以 `弧光：人物-事件` 记入 topics 日志行；写前查日志，别跳步、别写重。

## 反差开关

每人一个"人设崩塌时刻"，偶尔崩一次效果最好（示例：毒舌 B 在妹妹面前秒怂；洁癖 C 私下囤外卖筷子；东北大妞 A 怕黑；ABC D 成语接龙无敌）。人物不能只端着人设，反差是喜剧最稳的来源。

## 固定搭配技

每对一个固定开场模式，写稿直接套用（示例）：
- A & B：A 抛蠢问题/神叨发言 → B 毒舌拆台 → A 反杀，三句固定流程。
- C & D：当众互怼 → 私下投喂关心 → 被起哄时装傻。
- B & D：B 摆事实考据，D 用英文/歪理解曲解，B 崩溃。
- B & C：竞争兄妹式，见面先比点什么，输的请客，对外人一致对外。
- A & C：室友式，C 边收拾边念叨，A 撒娇蒙混。
- A & D：傻白甜二人组，鸡同鸭讲但意外合拍。

## 台词库

可借鉴经典影视台词，**化用为主**：整句引用必须做中文改编、不干念英文；英文原句偶尔来一句也行（初中水平，后面跟一句中文点意）；**每期全场最多用 3 次**，分散在不同人身上，用多了成复读机。
